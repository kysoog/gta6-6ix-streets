Vice Meridian — an open-world neon crime sandbox that runs in one browser tab. Three.js city, drivable cars, pedestrians, a wanted system, and a minimap, all vendored with no network calls.

## Run it

```sh
npm install
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
node serve.ts        # then open http://localhost:8080
```
